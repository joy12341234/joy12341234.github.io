# 윤재호 포트폴리오

가상 공간과 영상을 기술로 만드는 개발자 윤재호의 포트폴리오 사이트입니다.

**사이트 주소:** https://joy12341234.github.io

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 사이트 본문 (소개, 프로젝트, 도구, 연락처) |
| `assets/style.css` | 디자인 |
| `assets/main.js` | 첫 화면 그린 스크린 키잉 효과 |
| `assets/img/` | 프로젝트 이미지 |

## 프로젝트 추가하는 법

`index.html`에서 `<article class="project">`부터 `</article>`까지 한 덩어리를 복사해 붙여 넣고, 글과 이미지 경로만 바꾸면 됩니다. 이미지는 `assets/img/`에 넣어 주세요.
